11 月 11 日，天猫双 11 的 Token 充值活动开启。和往年不同的是，**Token 第一次作为独立品类出现在双 11 的主会场里**，而不是挂在某个云厂商的店铺角落。

参与的厂商和折扣大致是这样：

- MiniMax 三款月卡全部五折
- 阿里云 Token Plan 两款月卡五折起
- 智谱周卡五折起
- 千问办公基础版会员月卡首月三折起
- Qoder 月卡 3.3 折，低至 19.9 元

两天前的 11 月 9 日，阿里云刚上调了 Token Plan 个人版的订阅额度：Lite、Essential、Standard 三档月费不变，月度额度提升约 74% 至 78%。Lite 从 1.15 万 Credits 提到 2 万，月费 39 元；Essential 从 2.55 万提到 4.5 万，79 元；Standard 从 4.5 万提到 8 万，139 元。

## 从"按 API 计费"到"卖套餐"

这两件事放在一起看，指向同一个变化：**推理能力正在从面向开发者的按量计费，转向面向普通用户的订阅零售**。

过去的定价逻辑是 API 调用量乘以单价，用户是后端工程师；现在的逻辑是"每月多少钱、给你多少额度"，用户可能是写周报的运营、做课件的老师、或者只是想试试的普通消费者。品类化是这一转变的标志——只有当一个东西的购买者足够多、比较维度足够标准化（价格、额度、模型档位），它才值得被单独摆上货架。

## 对开发者意味着什么

短期是好事：同样的预算能买到更多调用量。但有几个细节值得留意。

第一，**额度单位并不统一**。Credits、Token、次数在不同平台之间不能直接换算，五折的比较基础可能完全不同。第二，**促销价的持久性未知**，用促销价做长期成本模型是危险的。第三，**套餐会把迁移成本前移**——当你把应用挂在某个平台的额度体系上，切换的摩擦从"改一行 API base"变成了"重新评估一整套配额"。

## 观察：价格战的终点是心智

把 Token 摆上双 11 的货架，本质上是在争夺"AI 额度"这个新品类的心智。谁先让用户形成"每月 39 元能买多少 Token"的直觉，谁就拿到了定价权。技术差距缩小之后，商业竞争会越来越像消费品行业——这对做技术的人来说，未必是好消息，但确实正在发生。
